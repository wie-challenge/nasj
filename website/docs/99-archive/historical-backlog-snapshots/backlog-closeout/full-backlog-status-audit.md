labels, priorities, milestones, timestamps and all Project items/Status fields. Stable story mappings
come from the canonical CSV and import state. Current board values override stale body Status metadata.

dependencies were evaluated; native dependency edges were not separately certified.

manifest still matches current source. Full acceptance/independent records supersede older records only
