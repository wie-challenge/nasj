# Archive index

**Last verified:** 1 November 2026.

Historical reports, audits and batch records. Every file here is a point-in-time record: it states
what was true on its date, not what is true at the current commit.

Nothing in this directory should be read as current status. For that, use
[Current status](../00-project/current-status.md) and [Known gaps](../08-backlog-and-acceptance/known-gaps.md).
