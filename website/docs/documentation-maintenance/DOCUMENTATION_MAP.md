Two folders are deliberately empty. `04-ai/` and `10-research-and-pilots/` have no grounded source
material; [Documentation gaps](DOCUMENTATION_GAPS.md) says so rather than filling them with
placeholder documents. Git does not track empty folders, so both exist only in a working tree.

## Deliberate deviations from the proposed tree

| Proposed | Actual | Reason |
|---|---|---|
| `04-ai/` with nine documents | `05-iot/wearable-overview.md` only | The AI service is not integrated and has no trained model. Nine documents would describe capabilities that do not exist. |
| `10-research-and-pilots/` | `competition/` retained | The competition package is a frozen deliverable with a hash-pinned review record. Restructuring it would break `pnpm competition:validate`. |
| `99-archive/` holds everything historical | `99-archive/` holds 111 dated Markdown reports; raw evidence stays under `engineering/evidence/` | Those evidence paths are referenced by surviving historical reports and are gitignored binaries. Moving them would break references for no gain. |
| Numbered folders everywhere | `competition/`, `engineering/`, `documentation-maintenance/` unnumbered | These are retained as-is to preserve working references and the submission validator. |
| An ADR in `02-architecture/architecture-decisions/` | Empty folder | No decision record has been written yet. The folder is kept so the first ADR has its required home; decisions currently live inside the batch reports in `99-archive/`. |
| `04-ai/` and `10-research-and-pilots/` populated | Both empty | Declared as honest gaps in [Documentation gaps](DOCUMENTATION_GAPS.md) rather than filled with placeholder documents. |

## Naming exceptions

Files are lowercase kebab-case, except two deliberate groups:

| Group | Files | Why |
|---|---|---|
| Frozen competition package | `docs/competition/*.md` | Hash-pinned by `pnpm competition:validate` and cited by the submission checklist. Renaming breaks the validator and the external review record. |
| Documentation maintenance record | `docs/documentation-maintenance/*.md` | Upper-case names are cited from the evidence-loss record and from sections of `99-archive/` reports written against them. Renaming would break the audit trail for the 31 October incident. |

Archived reports under `99-archive/historical-backlog-snapshots/` and the backlog-verification bundle
also keep their original upper-case names where they were generated by tooling; those are historical
artefacts, not authored documentation.
