# Data policy

No real dataset is included or loaded. `data/raw/` is ignored by Git.

Nasouj's knowledge articles will live in `knowledge/` (see [the plan](../docs/nasouj-assistant-plan.md)). They describe the platform and must contain no personal data.

Never send names, phone numbers, health readings, sensor streams or wearable participation to a model. Before using any real data, document its purpose, consent or legal basis, owner, allowed fields, retention, and access and deletion rules.
