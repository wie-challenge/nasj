# Evaluation protocol

No model accuracy result is claimed. Unit tests verify deterministic rules and arithmetic using synthetic fixtures.

E11-05 requires immutable forecasts recorded before real outcomes and genuine completion labels. Define the cohort and cancellation/missing handling. Report sample size, absolute error in calendar days, median error, coverage and craft/context breakdowns where privacy permits. Never evaluate against labels generated by the predictor itself.

Learned models must improve on the rules baseline on held-out time periods without leakage. Audit missingness and operational changes. Sparse or out-of-scope evidence requires an inconclusive result, not an invented accuracy percentage.
